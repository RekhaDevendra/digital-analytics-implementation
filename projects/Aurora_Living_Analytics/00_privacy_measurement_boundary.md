# 00 — Privacy & Measurement Boundary

## Purpose

Define the privacy boundary for the Aurora Living Analytics Lab
before any analytics or tag implementation is created.

## Public Visitor Policy

Ordinary visitors to the public Analytics Lab website
will not be tracked for analytics purposes.

## Analytics Collection

Public visitor analytics collection:
OFF

Advertising / remarketing:
OFF

Cross-site visitor tracking:
OFF

Personally identifiable information:
NOT COLLECTED

## Controlled Testing

Analytics implementation may be tested deliberately by the
Analytics Lab owner in a controlled testing context.

Controlled testing is for:

- GTM implementation
- GA4 configuration
- dataLayer validation
- event testing
- DebugView validation
- Network request validation
- QA documentation

Controlled test activity must not be treated as ordinary
public visitor analytics.

## Data Minimization

Only data required for controlled implementation testing
will be used.

No:

- names
- email addresses
- phone numbers
- passwords
- authentication tokens
- payment information
- sensitive personal information

## Advertising

Advertising and remarketing are out of scope.

## Implementation Principle

Privacy requirements are established before
measurement implementation.

No GTM tag should be created unless its purpose,
data requirements, privacy implications, and testing
method are documented.
