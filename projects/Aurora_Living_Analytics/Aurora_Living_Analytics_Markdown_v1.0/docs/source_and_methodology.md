# Sources & Methodology

## Primary learning source

Analytics Mania course materials supplied in the project.

Relevant course concepts used in this case study include:

- Business discovery and stakeholder questions
- Identifying business goals
- SMART goals
- KPIs and targets
- Measurement planning
- Prioritizing implementation
- Measurement plan vs. tag implementation plan
- GA4 events and recommended ecommerce events
- Event parameters
- Naming conventions
- Key events
- Purchase/ecommerce tracking
- Data Layer
- DVTT Framework
- GTM testing and publishing

## Official documentation

During implementation, verify event names, parameters, ecommerce requirements and platform behavior against current official Google documentation.

## Analytics Mania

Use for practical GTM/GA4 implementation patterns and troubleshooting.

## Simo Ahava

Use for advanced GTM/Data Layer implementation patterns where the standard approach is insufficient.

## Methodology rule

Do not use a source simply because it recommends an event or metric. Every implementation choice should connect to a documented business question or measurement requirement.
