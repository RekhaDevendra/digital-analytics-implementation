# End-to-End Digital Analytics Projects

## Aurora Living — Analytics Lab Case Study

**Status:** Strategy complete → GTM implementation next  
**Version:** 1.0  
**Project type:** Analytics learning / test website  
**Primary stack:** GA4 + Google Tag Manager

### Case-study flow

1. Business discovery & measurement strategy
2. Stakeholder discovery & business questions
3. Measurement plan
4. KPI framework
5. Event taxonomy
6. Data Layer specification
7. GTM implementation plan
8. QA & testing plan
9. Reporting requirements

### Working principle

We start with **business outcomes**, translate them into **website goals**, define **KPIs and targets**, decide what needs to be measured, and only then design the technical GA4/GTM implementation.

The measurement plan is intentionally separate from the technical tag implementation plan. The course materials emphasize that the measurement plan is strategic planning, while the later tag implementation plan describes the technical data points and GTM work.
